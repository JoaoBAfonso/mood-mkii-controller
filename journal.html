Local storage & backup

Imported audio and recordings are stored in this browser, on this device. Nothing is uploaded. This local library is not an account-protected vault: anyone using this browser profile can open it. Clearing browser data can erase it.

Export a backup regularly. It includes local audio and metadata only; Google Drive entries are not copied into backups. Large libraries need memory and disk space to export. Dedicated MIDI modules will be added separately.
